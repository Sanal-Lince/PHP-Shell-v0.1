# PHP2Scope v0.3.0 — Release notes

## Release title
**PHP2Scope v0.3.0 — Batch Domain Assessment & Linux Release Packaging**

## Summary
This release improves the passive PHP CVE triage workflow for authorized security teams by adding domain-list upload and sequential batch assessments to the browser wizard, while retaining single-target and CLI workflows.

## Highlights
- Upload `.txt` / `.csv` domain lists or paste URLs/hostnames (maximum 50 targets per batch).
- Review per-target PHP version observations, triage labels, confidence and request errors.
- Export per-target evidence reports in DOCX/PDF when reporting is enabled.
- Linux install and start scripts for the browser and CLI interfaces.
- GitHub Actions workflow to create standalone Linux x86_64 CLI/web executables and attach checksums to GitHub Releases.
- Updated documentation and version metadata.

## Security model
Passive-only. The tool does not send exploit payloads, submit forms, fuzz parameters, or automatically crawl discovered endpoints. A PHP banner or CMS fingerprint is not proof of vulnerability. Use only on systems for which you have explicit authorization.

## Known limitations
- Public sites frequently hide the PHP runtime version; unknown is an inconclusive result.
- Vendor backports and the actual web-serving runtime must be verified by the asset owner.
- Batch targets are processed sequentially; the current browser batch summary presents report endpoint paths as text. Detailed report downloads are available from each individual assessment result.
- The included launchers require Python dependencies; standalone Linux executables are generated by the GitHub Actions release workflow.

## Verification
Run `python -m unittest discover -s tests -v` in an installed environment. Release workflow artifacts are Linux x86_64-specific.
